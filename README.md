# 🎬 영상 소스 다운로더

영상 편집 소스를 **원본 최고 화질**로 받아주는 프로그램이에요.
유튜브 · 인스타그램 · 틱톡 · 도우인 · 샤오홍슈 — 여러 URL을 붙여넣으면 3개씩 동시에 받아요.

## 받는 법 (처음 한 번만)

```bash
git clone https://github.com/dwshin-dev/auto-downloader.git
```

1. 받은 폴더에서 **`처음-설치.command`를 더블클릭** — 필요한 건 전부 자동 설치돼요 (ffmpeg 포함, 따로 설치할 것 없음)
2. **`영상 다운로더` 아이콘을 더블클릭** → 터미널 창 없이 켜지고 브라우저가 자동으로 열려요

끄는 건 화면의 **🔴 프로그램 끄기** 버튼 또는 **독 아이콘 우클릭 → 종료**.
(`실행.command`는 오류를 확인해야 할 때 쓰는 용도로 남겨뒀어요)

👉 자세한 사용법: [docs/사용법.md](docs/사용법.md)

## 주요 기능

- **원본 최고 화질** mp4, 여러 URL 동시(3개) 다운로드
- **자막 가져오기** — 타임스탬프와 함께 표시, 전체 복사 버튼, 영상 옆에 .txt로도 저장
- **🎧 소리 듣고 자막 만들기** — 자막 없는 영상은 음성인식으로 (내 컴퓨터에서 처리, 무료)
- **🛠️ 편집용 파일 만들기** — 가변 프레임 영상(캡컷에서 소리 밀림)을 자동 감지해 고정 프레임 사본 생성
- **저장 위치 바꾸기** — 바탕화면, 외장하드 등 원하는 곳으로

## 저장 위치

받은 영상은 `다운로드/영상소스/` 폴더에 `업로드날짜_제목.mp4`로 저장돼요.
(화면의 "저장 위치 바꾸기" 버튼으로 변경 가능)
